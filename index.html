两张 grid 的解码预览

灰度图是用解码出来的深度值重画的（不是另一次渲染）；青色十字 = 探针所在像素，黄色十字 = 同一个深度值落在另一张 grid 的位置。

各趟 pass

  • #2（8773）camera 光栅化 → lightMVP(绕 Y) 的 z（NDC）
  • #3（8774）light 光栅化 → lightMVP(绕 Y) 的 z（NDC）
  • #4（8771）camera 光栅化 → lightMVP(绕 X) 的 z（NDC）
  • #5（8772）light 光栅化 → lightMVP(绕 X) 的 z（NDC）
  • #0 / #1（无端口）light / camera 光栅化 → 世界坐标深度，留作核对与定位表用

#2↔#3、#4↔#5 各自输出同一个量，区别只在“谁光栅化出来的 fragment”，对比就是 non-matching。

说明

  • mesh 就是参数文件里写死的 3 个顶点，没有任何几何生成。
  • 所有 pass 用同一份顶点 / 同一个 M / 同一个 P，viewport 都是 180×180。
  • 两个 light 视角的基准 eye 与 camera 相同（见 src/mesh-params.mjs 的 VIEWS）：一个绕 X 转（动 y/z），一个绕 Y 转（动 x/z），角度各自可调；camera 不转。
  • 片元颜色 = 值的 24bit 定点打包，alpha = 有没有 fragment；读回像素就能反解成数值。
  • 每趟 pass 在 draw 之前都 await 了对应 MeshRender 的 ready()。
  • 静态一帧，没有 mainloop。
